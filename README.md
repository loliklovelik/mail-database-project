# Информационная система для почтового сервиса

> Курсовая работа по базам данных. Автоматизация учёта почтовых отправлений, сотрудников и отделений.


---

## 📖 О проекте

Разработана **ИС почтового сервиса** для автоматизации учёта почтовых отправлений, сотрудников и отделений.

**В чём суть:**
- Клиенты отправляют корреспонденцию через почтовые отделения
- Система хранит данные о клиентах, сотрудниках, отправлениях, типах отправлений, отделениях, городах и регионах
- Реализована ролевая модель доступа (оператор, экономист, директор)
- Поддерживаются аналитические запросы, триггеры и хранимые процедуры

**Стек технологий:**
- **СУБД:** MySQL
- **Язык запросов:** SQL

---

## Используемые технологии

- MySQL — система управления базами данных
- SQL — язык запросов
- Хранимые процедуры — автоматизация аналитики
- Триггеры — обеспечение целостности данных
- Ролевая модель доступа — разграничение прав

---

## Функционал

**База данных:**
- 9 таблиц: `regions`, `cities`, `positions`, `shipment_types`, `postal_offices`, `clients`, `employees`, `employee_schedules`, `shipments`
- Связи один-ко-многим
- Нормализация до 3-й нормальной формы
- ER-диаграмма и даталогическая модель

**Хранимые процедуры (10 шт.):**

| № | Название | Описание |
|---|----------|----------|
| 1 | `pros1` | Количество отправлений по типам за день в отделении |
| 2 | `pros2` | Список сотрудников с количеством отправлений по типам |
| 3 | `pros3` | Дата первого отправления клиента |
| 4 | `pros4` | Расписание работы сотрудника |
| 5 | `pros5` | Суммарная стоимость отправлений сотрудника |
| 6 | `pros6` | Сотрудник с наибольшим количеством отправлений по типам |
| 7 | `pros7` | Среднее количество отправлений в день по регионам |
| 8 | `pros8` | Клиенты с более N отправлений за период |
| 9 | `pros9` | Среднее время доставки по типам за месяц |
| 10 | `pros10` | Список клиентов с общими затратами |

**Триггеры (7 шт.):**

| № | Название | Описание |
|---|----------|----------|
| 1 | `shipment_cost` | Автоматический расчёт стоимости отправления |
| 2 | `check_max_weight` | Проверка максимального веса |
| 3 | `update_status` | Обновление статуса при получении |
| 4 | `check_duplicate_passport` | Проверка дублирования паспортных данных |
| 5 | `one_director` | Ограничение: только один директор в отделении |
| 6 | `normalize_fio` | Приведение регистра ФИО |
| 7 | `normalize_phone_number` | Приведение номеров телефона к формату +7 |

**Ролевая модель доступа:**

| Роль | Права |
|------|-------|
| Оператор | SELECT, INSERT, UPDATE (clients, shipments, shipment_types) |
| Экономист | SELECT (clients, shipments, shipment_types, employees, employee_schedules) |
| Директор | ALL PRIVILEGES (полный доступ) |
